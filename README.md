# Business-dashboard-analysis

## Tools Used
- Microsoft Excel/Metabase
- Google Sheet
- Pivot Tables
- Charts & Graphs
- Data Cleaning Techniques

## Dataset Description
The dataset contains:
- Date
- Product
- Category
- Region
- Salesperson
- Expense
- Profit
- Profit Margin

## Data Cleaning Process
- Removed Duplicate
- Handled missing values
- Standardized data format
- Oranized data for analysis

## Dashboard Features
- Product Order
- Profit margin by category
- Sales by region
- Sales by category
- Top 10 best selling products
- Daily profit trend
- Sales vs Expense vs Profit

## Key Insights
- Monday has the highest profit.
- Friday has the highest expenses.
- The weekly growth was not constant, it's decreases everyday.
- Appliances generated the highest sales.
- North Region has the highest sales record.
- Blender generated highest sales.
- Product(Table) was order the most.
